# Saumya Kiswani — Resume Website

IIM Bangalore BBA (Digital Business & Entrepreneurship) midterm web development project.

## Files
- `index.html` — page structure and content
- `style.css` — colours, typography, layout and responsive styling
- `assets/profile.jpg` — add your own professional photograph here

## Before publishing
1. Add your photograph to `assets/` and name it `profile.jpg`.
2. Open `index.html` in a browser and check the page.
3. Check all links and spelling.
4. Upload the folder contents to your GitHub repository.
5. Enable GitHub Pages from repository Settings → Pages.
